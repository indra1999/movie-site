core-data/  — ডেটা সিস্টেম (এই ফোল্ডার বারবার এডিট করার দরকার নেই)

store.js      : সব ডেটা কোথায় সেভ হয় তার একমাত্র জায়গা (পোস্ট, পাবলিক কমেন্ট, API key, ডিলিট করা id)
demo-data.js  : ডেমো পোস্ট ও ডেমো Upcoming (এডমিনে এসে এগুলো এডিট/ডিলিট করা যায়)
config.js     : চাইলে TMDB API key এখানে একবার বসিয়ে রাখতে পারেন (ঐচ্ছিক)

নিয়ম: এডমিন প্যানেলের UI/ফিচার যত খুশি বদলান, শুধু store.js-এর KEYS-এর নাম বদলাবেন না।
